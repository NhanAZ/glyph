# Project guidance

## Interface

- Use Katorly's OreUI Web Components as the primary interface component library.
- Preserve the atlas editing behavior, file formats, and browser-side data handling when changing the interface.
- Use project-specific styles for the glyph atlas and other features that OreUI does not provide.

## Writing and punctuation

Apply these rules to ordinary English and Vietnamese prose in documentation, code comments, interface text, commit messages, pull requests, and agent-authored content.

- Do not use U+2014 or U+2013 as punctuation. Use the ASCII hyphen only when a dash is needed.
- Prefer periods, commas, conjunctions, and parentheses to separate ideas.
- Limit colons in ordinary prose. Avoid label-and-explanation phrasing when a natural sentence is clearer.
- Avoid semicolons in ordinary prose. Use a period or a comma with a suitable conjunction.
- Keep each sentence focused on one main idea when that improves clarity.
- Use straight double quotation marks by default.
- Treat these as writing defaults, not absolute bans. Preserve programming syntax, Unicode data, glyphs, direct quotations, and technical text where the characters or punctuation are required.
