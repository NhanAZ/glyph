# Project guidance

Keep Glyph Tools client-side and suitable for GitHub Pages. Preserve its GPL-3.0 license and retain attribution and usage notices for bundled Minecraft assets. Reuse the existing atlas and Unicode logic when changing the interface. Run `npm run check` and `npm run build` when changing application code.

## Writing

For ordinary English and Vietnamese prose in documentation, comments, interface text, commit messages, and pull requests:

- Do not use Unicode `U+2014` or `U+2013` as punctuation. Use an ASCII hyphen only when needed.
- Prefer complete, natural sentences. Avoid label fragments, excess colons, and semicolons. Use periods, commas, and conjunctions to connect ideas.
- Use straight double quotes by default.
- Do not apply these rules to code syntax, Unicode data, glyphs, verbatim quotations, or technical content that must remain exact.
